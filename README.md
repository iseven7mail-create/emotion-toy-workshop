# 心情玩具屋｜情緒之鏡

兒童情緒探索互動網站，以 38 張復古玩具牌卡陪伴孩子認識感受。

## 使用方式

開啟 GitHub Pages 網站，選擇陪伴角色、翻開三張牌，挑選符合當下心情的牌卡。也能瀏覽全部牌卡，直接記錄每日心情。

## 功能

- 男孩、女孩或暫不選擇角色
- 隨機翻牌、完整牌庫、搜尋、放大閱讀及下載
- 自我照顧小行動
- 每日心情、強度、文字日記與月曆
- 編輯日記、回顧感受、JSON 匯出與匯入

## 日記資料

日記只儲存在目前瀏覽器，不會傳送到 GitHub，也沒有雲端同步。請定期匯出備份。不同網址的瀏覽器儲存空間不同；若從原 Sites 網站搬過來，請先在原網站匯出，再於此站匯入。

## 部署

此專案為無建置步驟的靜態網站。在 GitHub Settings → Pages 選擇 Deploy from a branch、main、/(root) 即可。
所有前端程式與圖片位於根目錄，使用相對路徑，可部署到 GitHub Pages 專案子路徑。

內容用於情緒覺察與交流，沒有評分，不是心理診斷。花精與脈輪名稱沿用牌卡設定。
